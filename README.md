# Honda Subcontinent Sales Data Processing

## Project Overview

This project standardizes and merges Honda sales datasets from India, Pakistan, and Bangladesh into one regional dataset using Python and Pandas.

## Objectives

- Load datasets from three countries
- Standardize column names
- Convert currencies to INR
- Convert ratings to a common scale
- Calculate discounts
- Calculate final prices
- Merge datasets into one regional dataset
- Export the processed dataset

## Technologies Used

- Python
- Pandas
- Google Colab

## Input Files

- hondu_india_sales.csv
- hondu_pakistan_sales.csv
- hondu_bangladesh_sales.csv

## Output File

- hondu_subcontinent_processed.csv
